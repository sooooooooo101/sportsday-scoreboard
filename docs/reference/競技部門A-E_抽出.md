## 各競技

### 競技A 借り人競走
- 1レース8人 × 4試合。お題カードを引き、当てはまる人を連れてゴール
- 得点：1位 7点／2位 5／3位 4／4位 3／5〜8位 1（個人の順位点をチームで合計）
- 上限：「マックス100点」
- 得点係：2 名（順位メモ、得点加算と発表）

### 競技B 玉入れ改
- 相手チームのメンターが背負って逃げるカゴに玉を投げる。攻守を交代して2回戦＋ボーナスラウンド
- 得点：1球 = 1pt、マイナス玉 1球 = −1pt、ボーナス 1球目 +3／2球目 +5／3球目 +10
- プラス玉80球・マイナス玉20球
- 集計係：2 名（青担当・白担当）
- ⚠ ボールの数がそのまま点になるため、100点満点にする換算の仕方が決まっていない

### 競技C ドッジボール
- 青19人 vs 白20人、1面で2試合
- 得点：勝ち 40点／引き分け 25点／負け 10点
- ⚠ 1試合で青と白を足すと 50 点。2試合なら合計 100 点になる、という意味かどうかは未確認

### 競技D 障害物リレー ※変更予定
- けんけん → バレリーナ10回転 → わなげ → ピンポン。青と白が2チームずつ、計4チーム
- 得点：1位 40／2位 30／3位 20／4位 10（4チームの合計が 100）

### 競技E メンターリレー ※変更予定
- 前半：青白対抗リレー（メンター3人＋生徒3人）。勝ち 50点／負け 30点（計80点）
- 後半：メンター・TA 6人のリレー。順位に応じて 20点を配分（メモ案：1位8／2位4／3位3／4位3／5位2）。細かい配分は未定
